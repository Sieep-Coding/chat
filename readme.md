# Secure Messaging Application
A modern, secure messaging application built with Go and web technologies, designed to provide end-to-end encryption for private communication.

## Prospective Features

- User registration and authentication
- End-to-end encryption using the Signal Protocol or Double Ratchet Algorithm
- Group messaging
- File sharing
- Self-destructing messages
- Flashy and colorful user interface tailored to gen-z

## Technologies Used

- Go (backend)
- HTML, CSS, JavaScript (frontend)
- Signal Protocol or Double Ratchet Algorithm (encryption)
- PostgreSQL (database)
